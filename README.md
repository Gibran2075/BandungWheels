# Buroq Transport

Website rental mobil premium untuk Karawang dan sekitarnya.

## Overview

Buroq Transport adalah konsep website rental mobil yang dirancang
dengan fokus pada pengalaman pengguna, visual premium,
dan conversion-focused layout.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive Design

## Features

- Responsive layout
- Interactive navigation
- Smooth scrolling
- Animated sections
- Interactive service cards
- Fleet showcase
- FAQ accordion
- WhatsApp CTA
- Mobile navigation
